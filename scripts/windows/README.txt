실기 서술형 연습 - 윈도우 실행 파일
====================================

start-app.bat      앱을 켜고 브라우저를 엽니다. 평소에는 이것만 더블클릭하세요.
                   처음 한 번은 준비 작업 때문에 몇 분 걸립니다.
                   서버가 뜬 것을 확인한 뒤에 브라우저를 열고,
                   30초 안에 못 뜨면 오류와 로그를 보여줍니다.

stop-app.bat       앱을 끕니다.

reinstall.bat      부품과 화면 빌드를 지우고 처음부터 다시 만듭니다.
                   업데이트 후 이상하게 동작할 때 쓰세요.
                   문제은행 데이터와 .env 는 건드리지 않습니다.

troubleshoot.bat   앱이 안 켜질 때 실행하세요. Node 버전, 폴더 상태, 포트를
                   점검한 뒤 서버를 이 창에서 직접 띄워 오류를 그대로 보여줍니다.
                   확인이 끝나면 Ctrl+C 로 종료하세요.

autostart-on.bat   윈도우에 로그인하면 앱이 자동으로 켜지도록 등록합니다.
                   등록해 두면 브라우저에서 http://localhost:4000 만 열면 됩니다.

autostart-off.bat  자동 시작을 해제합니다.

run-hidden.vbs     내부용. 콘솔 창 없이 서버를 띄웁니다. 직접 실행하지 않아도 됩니다.


바탕화면에 바로가기 만들기
--------------------------
start-app.bat 을 오른쪽 클릭 - [보내기] - [바탕 화면에 바로 가기 만들기]


업데이트한 뒤에는
------------------
start-app.bat 이 package.json 변경을 감지해 새 부품을 자동으로 설치하고,
화면 소스가 바뀌었으면 다시 빌드합니다. 따로 할 일은 없습니다.
그래도 이상하면 reinstall.bat 을 실행하세요.


앱이 안 켜질 때
---------------
1. troubleshoot.bat 을 실행해 오류 메시지를 확인하세요.
2. 서버 로그는 server\data\server.log 에 남습니다.
3. 포트를 바꿨다면(.env 의 PORT) 이 스크립트들은 4000 을 기준으로 하니
   .env 의 PORT 를 4000 으로 두거나 스크립트의 4000 을 바꿔 주세요.
